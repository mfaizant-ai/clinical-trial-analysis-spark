# Clinical Trial Analysis Using Big Data Technologies
## What it does
This project analyses a large clinical trials dataset to uncover patterns across trial types, sponsors, medical conditions, and time. It runs a set of query-driven analytical tasks at scale using big data tools.

## Why I built it
This was a coursework assignment for my MSc in Artificial Intelligence at the University of Salford.

## Tools used
SQL, Apache Spark SQL, Databricks.

## How to run it
1. Clone this repository and install the dependencies.

2. Load the clinical trials dataset into your Databricks workspace.

3. Run the notebook to execute the four analytical tasks using Apache Spark SQL.

4. Review the output tables and charts for each analysis.

## Results
The analysis covered four tasks: trial-type distribution, sponsor rankings, condition frequency, and temporal trends. All queries were run at scale on Databricks, producing clear, query-driven insights across the full dataset.
